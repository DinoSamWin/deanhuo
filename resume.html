CASE STUDY 01

aosu HomeBrain

From Event Detection to AI Security Intelligence 从单纯的“事件检测”到“AI 智能安防大脑”
AI Security System Smart Home Visual Understanding LLM ReID Face Recognition Subscription Service
HomeBrain AI Loop HomeBrain AI 赋能闭环
Danger Detection 危险检测
Risk Classification 风险分级
AI Security Briefing 安防简报
Natural Language Search 语义检索
Subscription Value 订阅转化
Background 项目背景
Traditional smart security cameras mainly help users see what happened. However, overseas home users increasingly face deeper problems: too many notifications, weak risk judgment, unclear family/stranger distinction, and difficulty finding critical video evidence. 传统智能安防摄像机主要解决“看见事件”的问题，但海外家庭用户真正面临的是通知泛滥、风险判断弱、家人与陌生人难区分、关键视频证据难定位等更复杂的问题。
Product Strategy 产品策略
Upgrade the product from event-based monitoring to a risk-driven AI security system. 将产品从“事件检测型监控设备”升级为“风险驱动型 AI 安防系统”。
Key Contributions 核心工作内容
  • Built an AI security loop from danger detection, risk classification, security briefing, to semantic video search. 构建「危险检测 → 风险分级 → 安防简报 → 语义检索」AI 闭环。
  • Introduced visual understanding and LLM capabilities to support semantic-level risk judgment. 引入视觉理解与大模型，实现语义级风险判断。
  • Combined face recognition and ReID to build an identity × behavior × location based AI security decision system. 结合人脸识别与 ReID，构建「身份 × 行为风险 × 事件位置」的 AI 安防决策体系。
  • Designed daily security briefings to summarize key home events and help users understand home security status within one minute. 设计每日安防简报，对家庭事件进行语义分类与重点总结，实现一分钟掌控家门安全状况。
  • Reconstructed video evidence search through natural language retrieval. 通过自然语言检索（Natural Language Retrieval）重构视频证据的全局检索与快速定位体验。
  • Supported the upgrade from hardware sales to AI subscription and cloud service business model. 打通商业闭环，推动公司从单纯的硬件销售向「AI 功能订阅 + 云服务」的 SaaS 模式升级。
Value Created 创造的价值
User Value 用户价值
  • Notification noise reduction & risk highlighting 大幅降噪，凸显高风险事件
  • Quick home status overview in 1 minute 一分钟快速了解全天安全状况
  • Smarter AI subscription perceived value 全面提升 AI 订阅服务的感知价值
Business Value 商业价值
  • Hardware differentiation & high-end competitiveness 打造高端硬件差异化与竞争壁垒
  • Unlocking high-margin software subscription growth 释放高利润率的 AI 软件订阅增长空间

Outdoor AI Camera

Software Definition for Global Smart Home Scenarios 面向全球智能家居场景的户外云台安防相机软件定义
Outdoor Camera PTZ Camera AI Detection Driveway Monitoring Yard Security Hardware-Software Integration
Background 项目背景
In overseas home security scenarios, users care not only about detecting people, vehicles, and pets, but also about whether the system can understand real household contexts such as yards, driveways, packages, strangers, and parking protection. 在欧美家庭安防场景中，用户关心的不只是粗放的人、车、宠识别，而是系统能否精准理解庭院、车道、包裹、陌生人、车辆违停看护等真实家庭生活空间及细节。
Product Strategy 产品策略
Define differentiated software capabilities based on real outdoor home scenarios and hardware forms. 基于海外家庭户外真实看护场景和硬件形态，定义差异化软件能力。
Key Results 关键成果与业绩

Major Responsibilities & Deliverables 核心工作内容
  • Led software definition and capability framework design for AI outdoor PTZ cameras. 主导 AI 户外云台摄像机的软件定义与跨端能力框架设计。
  • Built AI care scenarios based on people, vehicles, pets, visual recognition, and acoustic recognition. 基于人 / 车 / 宠识别与基础感知，构建出包含声学特征在内的多模态 AI 智能看护体验体系。
  • Designed high-frequency home security features such as zone intrusion monitoring and automatic parking protection. 围绕欧美家庭庭院与车道场景，高保真设计区域闯入监控、智能车道停车保护、自动寻迹防盗等高频场景级安防机制。
  • Coordinated firmware, app, and cloud teams to ensure cross-end capability delivery. 统筹固件、App、云端微服务多端协同，保障复杂分布式 AI 交互在千万量级设备上的稳定落地。
  • Built reusable AI capability foundations for multiple product lines. 主导全系平台级多源感知基础能力中台建设，形成高重用性的 AI 方案货架。
  • Supported AI feature subscription and cloud service commercialization. 设计从硬设备到软方案的无缝购买引导，全面打通 AI 能力订阅与大容量云服务的商业化变现漏斗。
